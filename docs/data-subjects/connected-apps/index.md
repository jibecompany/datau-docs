# Connected Apps

**Connected apps** are the tools you can open from your DataU account. They all share a single
sign-on session managed by DataU, so once you log in you can move between them freely — and every
one of them respects the same consent and data-sovereignty rules.

The apps you see depend on your account role: citizens see the tools for managing and sharing their
own data, while researchers see the tools for designing studies and exploring anonymised results.

## SPOON Project

The main set of connected apps is the **SPOON toolset** — the EU-funded digital tools built for the
SPOON Horizon Europe project.
