# SPOON Project

**SPOON** (Sustainable Personalised cOnsumer fOod behaviour ecosystem on Nutrition) is a Horizon
Europe citizen-science project investigating food-consumption behaviour and the transition toward
healthier, more sustainable diets across the EU. It combines empirical research, citizen-driven data
collection, and a shared digital infrastructure that lets researchers, citizens, and the food chain
interact under clear data-governance rules.

The **SPOON toolset** is the suite of applications you use to take part. They are built on the DataU
platform, so every interaction — logging in, answering a questionnaire, sharing a data item — is
governed by consent and data sovereignty.
