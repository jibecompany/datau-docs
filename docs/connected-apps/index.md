# Connected Apps

**Connected apps** are the apps integrated with DataU.

## SPOON Project Connected Apps

At the moment, the main set of DataU connected apps is the **SPOON toolset** — the EU-funded digital tools built for the
SPOON Horizon Europe project.

They all share a single sign-on session managed by DataU, so once you log in you can move between them freely — and every
one of them respects the same consent and data-sovereignty rules.

The apps you see depend on your account role: citizens see the tools for managing and sharing their
own data, while researchers see the tools for designing studies and exploring anonymised results.
